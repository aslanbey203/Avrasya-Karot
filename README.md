# AVRASYA KAROT V3

Next.js 16 + Tailwind CSS kurumsal web sitesi.

## Kurulum

```bash
npm install
npm run dev
```

## Firma bilgileri

Tüm telefon, WhatsApp, isim ve adres bilgileri `app/lib/site.ts` dosyasından yönetilir.

## Alan adı

`.com` alan adı bağlandığında `app/lib/site.ts` içindeki `siteUrl` değerini değiştirin.
